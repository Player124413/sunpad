# Contributing

SunPad is an experimental Apple-platform static-recompilation integration.
Small, reproducible fixes are welcome.

Before opening a pull request:

1. Run `./scripts/check-repository.sh`.
2. Keep changes focused and explain what was tested.
3. Distinguish compilation, launch, visible runtime, and hands-on gameplay
   evidence.
4. Do not attach or commit a disc image, extracted game data, generated game
   code/module, save, signing material, device container, or private log.
5. Review diagnostic logs before sharing them; remove personal paths and
   device-specific information that is not needed for the report.

By contributing, you agree that your contribution is licensed under the
repository's GPL-3.0-or-later license.
