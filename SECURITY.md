# Security

Do not include game data, saves, signing material, credentials, device
containers, or unreviewed diagnostic logs in a public issue.

For an ordinary crash or compatibility problem, use the bug-report template
and include only the minimum relevant log excerpt. For a vulnerability that
would put users or their data at risk, contact the maintainer privately through
the GitHub profile before publishing details. If private vulnerability
reporting is enabled for this repository, prefer that channel.

SunPad is currently a source/development project, not a supported App Store,
TestFlight, or public IPA distribution.
